FECHADO EM CODIGO F-01: superAdminEmails legivel por qualquer autenticado

Evidencia: SystemSettingsContext.tsx Bloco 7 Phase B | Docs: SYSTEM_SETTINGS_EXPOSURE.md, FIRESTORE_RULES_DIFF.md
Client nao le mais `systemSettings/config` via SDK, defaults sensiveis no client sao vazios e `/api/me/session` nunca retorna `superAdminEmails`. Super admin complementa com `/api/admin/settings`. Pendente apenas a publicacao manual de firestore.rules.proposed para restringir a leitura de `config` no Firestore a super admin.

Advisories high em `xlsx`. Aceitos formalmente com mitigacao via limites de upload. Reabrir se surgir critical.

Logger com niveis silent/error/debug. Silent default em NODE_ENV=test. Redaction mantida.
