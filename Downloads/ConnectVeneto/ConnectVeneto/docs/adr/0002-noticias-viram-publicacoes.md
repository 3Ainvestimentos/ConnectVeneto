# Notícias viram Publicações

O feed de Notícias (`newsItems`, sem autor, sem data de criação, publicado só por quem tem `canManageContent`) é substituído pelo Hub de Comunicação Interna. As Notícias publicadas migram como Publicações no canal "Institucional" e o admin de Notícias é aposentado, em vez de manter os dois sistemas em paralelo. Só Publicadores publicam (permissão por canal; a Comunicação publica em todos) — decidimos não abrir a publicação para todos os colaboradores para evitar ruído.
